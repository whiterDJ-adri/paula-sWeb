# Dogmas

Normas fijas para cuando la IA (Claude u otra) implemente cosas de forma automatizada
en este proyecto. La idea: en vez de repetir "cambia el nombre de la foto, ya sabes cómo
lo quiero" cada vez, la norma queda escrita acá una vez y la IA la sigue sola.

## Cómo se usa

- Un archivo por tema (`nomenclatura-imagenes.md`, `nomenclatura-componentes.md`, etc.).
- Cada norma debe tener ejemplos concretos de "bien" y "mal" — una regla sin ejemplo se
  interpreta mal.
- Si una norma cambia con el tiempo, se edita el archivo directamente (no se acumulan
  versiones viejas).
- Antes de hacer un cambio automatizado que toque nombres, estructura de carpetas,
  convenciones de código, etc., la IA debería revisar si ya hay un dogma que aplique acá.
